让语音输入成为 AI 产品的基础层。

VILab 把录音、转写路由、热词上下文、文本清理和远程服务接入收束成一套可持续演进的声音输入平台，既服务桌面用户，也服务团队和 SDK 集成。

桌面客户端 / 远程服务 / Public API / 公开发布链路

统一语音入口

桌面客户端负责快捷键、录音、转写反馈、复制粘贴和本地交互，把语音输入先做成可每天使用的产品体验。

VILab 的定位不是“语音转文字按钮”，而是长期演进的声音输入层：需要低延迟和控制感时运行在本地，需要团队复用和统一路由时运行在服务端。

当前公开版本：v0.2.21。这个站点把安装包、更新日志、文档和 updater feed 放在同一个可信入口里。

架构

一层语音能力，多种运行形态。

项目正在从单一桌面工具演进为可复用的语音平台：桌面 App、内嵌本地服务、无头服务端、局域网部署和 SDK 客户端，都通过同一套 Public API 边界协作。

产品重点

这个公开站点要讲清楚什么。

它应该像基础设施页面，而不是泛 AI 落地页：清楚、可信、可安装、可集成，并且能让用户理解 VILab 为什么不只是一个听写工具。

01

公开发布可信

安装包、更新 manifest、文档和更新日志放在一起，用户能确认自己下载和升级的内容。

02

服务端边界清晰

普通客户端只保存 Server URL 和 external API key；Provider Key、路由和 Admin 能力留在服务端。

03

长期语音理解

热词上下文、文本后处理、坏例沉淀和 replay eval 指向一个会逐渐理解用户表达习惯的平台。
