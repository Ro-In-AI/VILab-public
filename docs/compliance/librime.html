librime 合规说明 ​

  • 组件：librime
  • 上游：https://github.com/rime/librime
  • 版本：1.13.1
  • 源码修订：1c23358157934bd6e6d6981f0c0164f05393b497
  • SPDX: BSD-3-Clause

VILab macOS 输入法仅集成 librime 核心库，并在构建时下载官方发布物用于本地打包。

本仓库不引入以下社区前端或非 Rime 拼音库到发布包：

  • Squirrel
  • fcitx5-macos
  • libpinyin

VILab Windows 输入法使用构建时生成的 rime_ice_windows Rime profile，基于开源 rime-ice 词库和拼音规则，并叠加 VILab 补充词表与用户词表。该 Windows profile 会移除当前 Windows payload 未随包提供的 Lua-only 过滤器。发布时需一并附带 librime 与词库来源对应的 LICENSE 文本。

VILab macOS 输入法仅随包保留 rime_ice_test profile，用作固定的完整 rime-ice 输入体验。
