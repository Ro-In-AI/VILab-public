VILab 0.2.10 - Windows startup and overlay focus fixes (2026-05-07 CST)

Windows startup

  • Hidden helper processes no longer open visible PowerShell or command windows during first launch.
  • Startup work is delayed and reduced so the desktop shell can appear sooner after installation.
  • Local STT state is restored without eagerly loading the previous model during app startup.

Floating overlay

  • The recording overlay now opens without activating itself on Windows, so the current typing app should keep focus when the global shortcut starts recording.
  • Quick Actions and settings windows still request focus when they need keyboard input.

Validation

  • Built from the local Windows release pipeline and verified with the packaged smoke test before publishing.
