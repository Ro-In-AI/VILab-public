VILab 0.2.25

VILab 0.2.25

Changes

  • 恢复流式听写在 ASR 后、LLM 前的热词替换层，确保实时识别结束后先应用用户词库再进入文本清理或润色。
  • 修复 realtime server 路径下历史记录缺少“热词替换”差异展示的问题，继续保留 rawTranscript -> verbatim -> polished 的分层可观察性。
  • 统一 realtime 与普通 server pipeline fallback 的热词处理语义，避免流式路径和录完后上传 WAV 路径出现不同输出。
  • 远程 server 模式下桌面端优先读取远程词库计算历史热词 diff，避免本地词库为空导致历史页无法展示热词替换结果。
