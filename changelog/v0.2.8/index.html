VILab 0.2.8 - Windows 本地版 (2026-05-06 CST)

VILab 0.2.8 - Windows 本地版 (2026-05-06 CST)

后处理与诊断

  • 强化听写后处理 Provider 回退与诊断透明度，失败时保留更完整的上下文与日志。
  • 优化高风险后处理的本地保真回退，降低专名、意图和语义被过度改写的概率。
  • 稳定 MiniMax 中文后处理表现，保留更自然的人味表达。

评估与数据工具

  • 新增 Typeless 数据集导出、回放和评分链路，用于离线复盘真实听写质量。
  • 建立听写后处理意图评估闭环，补充结构化样本和质量评估日志。

词典体验

  • 简化词典批量导入入口，默认收起导入面板，减少首屏干扰。
  • 精简中英文导入文案，同时保留逐行粘贴和 .txt/.tsv/.csv 文件导入能力。

验证

  • 本版本 Windows 安装包使用本地机器构建和本地 smoke 验证，不使用 GitHub Actions 或云端构建。
  • 本次公开发布仅包含手动安装包和 SHA256 校验文件；自动更新资产会在本地签名密钥与应用内公钥匹配后再恢复。
