VILab 0.2.7 - Windows 本地版 (2026-05-01 20:52 CST)

VILab 0.2.7 - Windows 本地版 (2026-05-01 20:52 CST)

Windows 版本

  • 修复 Windows 快捷键设置阶段的卡顿和弹窗问题：快捷键录制会先暂停全局快捷键监听，避免录制新快捷键时被旧快捷键重复触发。
  • 修复偏好保存顺序：保存快捷键前先注册校验，新快捷键不可用时不会写入配置；保存失败时会恢复旧快捷键。
  • 修复启动阶段快捷键冲突后的重试策略：普通快捷键冲突不再持续重试，避免 Windows 上反复弹框和后台卡顿。
  • 修复语音转录结束后的插入兜底：录音开始时会捕获前台窗口、线程、focused control 和 caret，结束时如果目标变化、caret 消失，或 Windows 没有暴露可靠 caret，则复制结果到剪贴板并保留右下角悬浮窗。
  • 改进右下角悬浮窗状态：当结果已复制到剪贴板时，悬浮窗会保留结果并显示可复制状态，方便用户手动复制或粘贴。

验证

  • 通过 Windows 插入目标回归测试：cargo test windows_text_target。
  • 通过启动快捷键回归测试：cargo test startup_shortcut。
  • 通过 Rust 编译检查：cargo check。
  • 通过悬浮窗与快捷键录制前端测试：vitest OverlayWindow/HotkeyRecorder。
  • 通过 TypeScript 类型检查：npm run typecheck。
  • Windows 安装包使用本地机器编译和本地 smoke 验证，不使用 GitHub Actions 或云端编译。
