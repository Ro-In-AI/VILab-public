VILab 0.2.9 - Windows updater key recovery (2026-05-06 CST)

VILab 0.2.9 - Windows updater key recovery (2026-05-06 CST)

自动更新与发布安全

  • 将 Windows updater 公钥恢复为当前本地发布私钥匹配的签名链，手动安装本版本后，后续版本可继续使用自动更新。
  • Windows 发布脚本新增 updater 签名密钥硬校验：本地 .key.pub 与 src-tauri/tauri.conf.json 不一致时会在构建前失败。
  • 新增手动安装包发布模式，允许在无可用 updater 私钥时只发布 EXE/MSI 与 SHA256，避免误上传无效的 latest.json 或 .sig 文件。
  • 已安装内嵌 FB66BF868AD839B5 公钥版本的用户需要手动安装本版本；签名链恢复后，后续版本再走自动更新。

验证

  • 本版本 Windows 安装包继续使用本地机器构建和本地 smoke 验证，不使用 GitHub Actions 或云端构建。
