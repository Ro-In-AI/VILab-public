VILab 0.2.13

VILab 0.2.13

Changes

  • 支持历史记录好/坏数据打标，坏例可继续填写问题标签、期望输出和备注。
  • 历史导出升级为 format v3，在 JSON、月度 manifest 和 workbook 中保留坏例结构化字段，便于沉淀 bad case 测试集。
  • 历史记录页面支持分层差异展示，便于区分原始识别、文本润色和最终输出之间的差异。
  • 收紧热词润色上下文，减少非用户热词内容被错误注入 prompt 的风险。
  • 修复 Ollama 局域网文本变换测试和 Windows 发布回归测试编译问题。
  • Windows 发布脚本补充 Rust 测试入口点降级开关和显式跳过 cargo 测试开关，保留安装包 smoke test 作为发布门槛。
