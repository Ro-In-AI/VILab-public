VILab 0.2.14

VILab 0.2.14

Changes

  • 新增 VILab Public API v1 契约，覆盖模型列表、音频转写、Pipeline 发现、Pipeline 执行和 NDJSON 流式事件。
  • 新增 Python 和 TypeScript SDK 的 Pipeline facade，并补充契约测试、打包校验和本地安装 smoke import。
  • 完善 SDK 发布元数据、README 和包内 MIT LICENSE，方便后续发布到 PyPI 和 npm。
  • 让 Windows 听写悬浮窗锚定到当前文本输入光标，优化听写时的上下文定位。
  • 补充客户端/服务端职责边界、Headless Server、安全边界和 API 版本兼容文档。
